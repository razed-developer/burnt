# Burnt UI assets

Place the in-app burnt-toast logo here as:

`burnt-toast.png`

Recommended:

- PNG with transparent background
- square canvas
- toast on a light plate
- no text
- at least 256×256 px (512×512 preferred)
- keep the toast and plate fairly close to the image edges so the mark remains readable at small UI sizes

The application header imports this file directly from `src/assets/burnt-toast.png`.
